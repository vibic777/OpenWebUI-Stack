# Экспорт изображений

Отдельный Action с меню SVG, PNG, JPG и WebP. WebP создаётся в браузере из найденного изображения PNG/JPG (или внутреннего файла Open WebUI) с проверкой декодирования и результата. Нужен современный браузер с `createImageBitmap` и WebP canvas. Код не требует дополнительных Python-библиотек.

Установка: `sudo ./install-functions.sh` (или `--email ADMIN_EMAIL`). Удаление только этого Action: `sudo ./remove-functions.sh`.

Промпт-тест для SVG: попросите вывести один fenced-блок `svg` с простым SVG без внешних ссылок, скриптов, `foreignObject` и обработчиков событий. PNG/JPG/WebP проверяйте на настоящем изображении, приложенном к ответу.
