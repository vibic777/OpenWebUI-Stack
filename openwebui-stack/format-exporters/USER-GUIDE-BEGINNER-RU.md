# Простые промпты для экспорта

Скопируйте нужный запрос в чат. После ответа нажмите кнопку соответствующей группы и выберите тот же формат. Не просите модель «создать файл» — она должна вывести содержимое, а Function скачает его.

## Изображения

### SVG

~~~text
Создай простую SVG-картинку 800×500 на тему «[тема]»: светлый фон, заголовок, три аккуратных фигуры и русские подписи. Верни только один полный SVG-код, без пояснений.
~~~

### PNG / JPG / WebP

~~~text
Создай настоящее растровое изображение: [опишите сцену, стиль, цвета и размер]. Не выдавай описание и SVG-код — нужен именно PNG/JPG-файл.
~~~

Если модель не умеет создавать изображения, прикрепите готовый PNG или JPG и нажмите IMG → PNG/JPG/WebP.

## Документы

### DOCX / PDF / Markdown / TXT

~~~text
Подготовь материал для [аудитория] на тему «[тема]»: заголовок, краткое введение, три раздела, список действий и вывод. Пиши по-русски, не выдумывай факты и выведи готовый текст без пояснений о создании файла.
~~~

Выберите DOCX, PDF, Markdown или TXT.

### XLSX

~~~text
Составь таблицу для Excel по теме «[тема]». Используй колонки: [колонка 1], [колонка 2], [колонка 3] и 5 строк данных. Верни только одну аккуратную Markdown-таблицу, в каждой строке должно быть одинаковое число ячеек.
~~~

### PPTX

~~~text
Подготовь план презентации из 5 слайдов на тему «[тема]». Для каждого слайда напиши заголовок второго уровня и 3 коротких пункта. Не используй таблицы и не добавляй пояснения.
~~~

### VSDX

~~~text
Опиши процесс «[название процесса]» в виде простой Mermaid-схемы: 5–7 узлов, одна проверка с вариантами «Да» и «Нет», стрелки и возврат к предыдущему шагу. Верни только один блок Mermaid без пояснений.
~~~

## Код

Во всех запросах ниже замените [задача] на свою задачу. Ответ должен содержать только один полный файл с кодом.

~~~text
Напиши безопасный PowerShell 7-скрипт для Windows, который выполняет такую задачу: [задача]. Добавь проверку ошибок и ничего не удаляй без явного подтверждения. Верни только один полный файл PowerShell.
~~~
Выберите CODE → PowerShell (PS1).

~~~text
Напиши Bash-скрипт для Linux, который выполняет такую задачу: [задача]. Добавь #!/usr/bin/env bash, set -euo pipefail и проверку аргументов. Не используй опасные команды без подтверждения. Верни только один полный файл Bash.
~~~
Выберите CODE → Bash (SH).

~~~text
Напиши программу на Python 3.11 для такой задачи: [задача]. Используй только стандартную библиотеку, обработай ошибочный ввод и верни только один полный файл Python.
~~~
Выберите CODE → Python (PY).

~~~text
Напиши безопасный VBA-макрос для Excel, Word или PowerPoint, который выполняет задачу: [задача]. Добавь обработку ошибок и не используй сеть или удаление файлов. Верни только один полный модуль VBA.
~~~
Выберите CODE → VBA (BAS).

~~~text
Напиши один законченный файл JavaScript для браузера или Node.js, который выполняет задачу: [задача]. Не используй внешние библиотеки без необходимости. Верни только код.
~~~
Выберите CODE → JavaScript (JS).

~~~text
Напиши один законченный файл TypeScript для [среда], который выполняет задачу: [задача]. Добавь типы для входных данных и результата. Верни только код.
~~~
Выберите CODE → TypeScript (TS).

~~~text
Напиши один законченный PHP 8-скрипт, который выполняет задачу: [задача]. Проверь входные данные и не добавляй внешние зависимости. Верни только код.
~~~
Выберите CODE → PHP.

~~~text
Создай одну самостоятельную HTML-страницу на тему «[тема]». Добавь заголовок, текст, список и простую форму. Верни только полный HTML-код.
~~~
Выберите CODE → HTML.

~~~text
Напиши один CSS-файл для оформления страницы [опишите внешний вид]. Добавь адаптивность для телефона. Верни только CSS-код.
~~~
Выберите CODE → CSS.

~~~text
Напиши один законченный Java-класс для задачи: [задача]. Используй только стандартную библиотеку и добавь main для примера запуска. Верни только код Java.
~~~
Выберите CODE → Java.

~~~text
Напиши один законченный файл C11 для задачи: [задача]. Проверь ошибки ввода и освобождай выделенную память. Верни только код C.
~~~
Выберите CODE → C.

~~~text
Напиши один законченный файл C++17 для задачи: [задача]. Используй стандартную библиотеку и обработай ошибочный ввод. Верни только код C++.
~~~
Выберите CODE → C++.

~~~text
Напиши один законченный файл C# для .NET 8, который выполняет задачу: [задача]. Используй стандартные средства .NET. Верни только код C#.
~~~
Выберите CODE → C#.

~~~text
Напиши один законченный файл Go 1.22 для задачи: [задача]. Обработай ошибки и верни только код Go.
~~~
Выберите CODE → Go.

~~~text
Напиши один законченный файл Rust 2021 для задачи: [задача]. Обработай ошибки через Result там, где это уместно. Верни только код Rust.
~~~
Выберите CODE → Rust.

~~~text
Напиши один безопасный SQL-запрос для PostgreSQL, который выполняет задачу: [задача]. Используй только SELECT на синтетических данных, без изменения таблиц. Верни только SQL-код.
~~~
Выберите CODE → SQL.

## Данные и конфигурации

Замените [данные] своими значениями и выберите DATA с тем же форматом.

~~~text
Преобразуй эти данные в валидный JSON: [данные]. Верни только JSON без пояснений и комментариев.
~~~
DATA → JSON

~~~text
Преобразуй эти записи в JSONL: [список записей]. Верни по одному валидному JSON-объекту в каждой строке и ничего больше.
~~~
DATA → JSONL

~~~text
Преобразуй эти данные в валидный XML с одним корневым элементом: [данные]. Верни только XML.
~~~
DATA → XML

~~~text
Преобразуй эти данные в валидный YAML: [данные]. Используй пробелы, не табуляцию, и верни только YAML.
~~~
DATA → YAML

~~~text
Преобразуй эти настройки в валидный TOML: [настройки]. Верни только TOML без пояснений.
~~~
DATA → TOML

~~~text
Преобразуй эти настройки в INI с секциями и парами ключ=значение: [настройки]. Верни только INI.
~~~
DATA → INI

~~~text
Создай конфигурационный файл CONF для программы [название программы] с такими настройками: [настройки]. Используй синтаксис этой программы и верни только содержимое файла.
~~~
DATA → CONF

~~~text
Преобразуй эти настройки в файл ENV: [настройки]. Используй только строки KEY=VALUE, без пояснений и секретов.
~~~
DATA → ENV

~~~text
Преобразуй эти настройки в Java Properties: [настройки]. Используй строки key=value и верни только содержимое файла.
~~~
DATA → Properties

~~~text
Преобразуй эти данные в CSV с заголовком и запятыми между колонками: [данные]. Верни только CSV.
~~~
DATA → CSV

~~~text
Преобразуй эти данные в TSV с заголовком и табуляцией между колонками: [данные]. Верни только TSV.
~~~
DATA → TSV

## Важно

Если появляется сообщение о неправильном блоке кода, проверьте выбранный формат и попросите модель вывести ровно один блок с нужной меткой. Для PNG/JPG/WebP нужен настоящий файл изображения, а не текстовое описание.
