# Экспорт документов V2 (DOC)

Одна кнопка класса. Экспортируется ответ, под которым нажали кнопку. Один найденный артефакт даёт один файл; несколько артефактов — отдельные файлы с одной UTC-меткой времени, порядковым номером и расширением формата. Разрешите множественные загрузки для Open WebUI, если этого попросит браузер.

Установка всех четырёх кнопок: `../install-functions.sh`. Удаление только V2: `../remove-functions.sh`. Скрипты V2 используют собственные ID с суффиксом `_v2` и не изменяют прежние экспортёры.
