# Экспортёры V2 для Open WebUI — сохранённый пакет

Версия: `2026.10.10.3`. Пакет содержит четыре Actions: IMG, DOC, CODE и DATA. Каждая кнопка обрабатывает ответ ассистента, у которого её нажали. Повторяющиеся артефакты сохраняются отдельными файлами с общей UTC-меткой времени и порядковым номером.

| Кнопка | Форматы | Поведение |
|---|---|---|
| IMG | SVG, PNG, JPG, WebP | SVG можно скачать или преобразовать в PNG/JPG/WebP в браузере. Для изображений используются найденные PNG/JPG, а при их отсутствии SVG рендерится в canvas. |
| DOC | DOCX, XLSX, PPTX, VSDX, PDF, Markdown, TXT | DOCX/PPTX создают по одному файлу на ответ. PDF открывает печать браузера: выберите «Сохранить как PDF». Для XLSX создаётся книга на каждую Markdown-таблицу либо одна книга с отдельным листом на таблицу. Для каждой Mermaid-диаграммы создаётся VSDX. Markdown/TXT сохраняют текст ответа. |
| CODE | PS1, SH, PY, VBA/BAS, JS, TS, PHP, HTML, CSS, Java, C, C++, C#, Go, Rust, SQL, Power Query | Каждый code fence распознанного языка сохраняется отдельным файлом. Power Query поддерживает расширения `.pq` и `.m`. |
| DATA | JSON, JSONL, XML, YAML/YML, TOML, INI, CONF, ENV, Properties, CSV, TSV | Каждый блок данных сохраняется отдельно. Если блоков CSV/TSV нет, Markdown-таблицы выгружаются по одной в CSV/TSV. |

Power Query распознаёт метки `m`, `pq`, `powerquery`, `power-query` и `power query`. Для пакетной загрузки IMG браузер должен разрешать несколько файлов. Внутренние ссылки принимаются только с того же origin Open WebUI.

## Совместимость

Пакет сохранён для уже существующих установок. Его Function ID совпадают с актуальным пакетом [`format-exporters-v2`](../format-exporters-v2/README.md), поэтому одновременно устанавливать оба нельзя. Для новых установок используйте актуальный пакет.

## Установка и удаление

Из каталога `format-exporters2` запустите `./install-functions.sh`; параметры `--img`, `--doc`, `--code`, `--data` позволяют выбрать классы функций. Для удаления явно укажите набор, например `./remove-functions.sh --all` или `./remove-functions.sh --doc`. Используются отдельные ID `export_*_menu_v2`; удаление этого пакета не удаляет Actions другого поколения.

Скрипты запрашивают e-mail администратора Open WebUI и скрыто читают его пароль. SSH-учётные данные для API не подходят. Для ручного импорта доступны `functions.json` в корне и манифесты в каталогах классов. Пакет содержит готовые Actions и не имеет отдельного поддерживаемого сборщика или набора проверок.
