# Очистка файлов, связанных только с чатами

`cleanup-chat-files.sh` предназначен для периодической уборки загруженных в чаты файлов при сохранении Knowledge.

## Что считается кандидатом

Скрипт включает файл только если он связан хотя бы с одним сохранённым чатом через `chat_file` и одновременно не найден в `knowledge_file`, `channel_file`, заметках, общих доступах к файлам или поле `collection_name`. Не связанные ни с чем файлы (orphan/unlinked) автоматически не удаляются: по одной записи нельзя надёжно определить, кому и для чего они нужны.

При удалении скрипт вызывает `DELETE /api/v1/files/{id}` в Open WebUI. Штатный endpoint удаляет запись файла, его объект в настроенном хранилище SeaweedFS и файловую Qdrant-коллекцию `file-{id}`. Перед удалением ещё раз проверяются связи. Коллекции Knowledge в Qdrant и записи Knowledge в PostgreSQL не выбираются.

Переписка, сообщения и история чата не удаляются. Удалённые вложения в старых чатах больше не откроются.

## Предпросмотр и удаление

На сервере:

```bash
cd /path/to/openwebui-stack
./cleanup-chat-files.sh
./cleanup-chat-files.sh --older-than 30
```

Обе команды только показывают кандидатов и их суммарный размер. Для очистки задайте срок хранения в днях:

```bash
./cleanup-chat-files.sh --delete --older-than 30
```

Скрипт скрыто запросит admin API key Open WebUI и попросит ввести подтверждение с точным числом файлов. Запускайте очистку, когда пользователи не добавляют файлы в Knowledge: API Open WebUI при удалении файла очищает связи Knowledge, поэтому повторная проверка скрипта защищает от уже появившихся связей, но не блокирует параллельное добавление в короткий момент между проверкой и запросом удаления.

Порог `--older-than` обязателен для удаления и не имеет значения по умолчанию. Сначала проверьте список без `--delete`; не используйте `--yes`, пока процесс не будет проверен на вашем графике хранения.

## Границы очистки

- Отбираются только файлы с явной связью с сохранённым чатом.
- Knowledge, каналы, заметки, общие файлы и файлы с неизвестной/неоднозначной связью сохраняются.
- Текст истории чатов в PostgreSQL и другие пользовательские данные не затрагиваются.
- Объекты SeaweedFS без записи Open WebUI `file` остаются нетронутыми: определить их назначение безопасно нельзя.
- Для ручной диагностики сервисов используйте `verify-stack.sh --all`, `check-qdrant.sh`, `check-seaweedfs.sh` и `check-valkey.sh`.

`wipe-rag.sh --vectors`, `--files`, `--all` и `--volumes` — глобальные операции. Они очищают данные Knowledge вместе с остальными и не подходят для обычной уборки чатовых файлов.
