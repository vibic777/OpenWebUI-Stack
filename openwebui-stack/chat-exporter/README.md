# Экспорт всего чата

`export_entire_chat` экспортирует историю текущего диалога Open WebUI одним файлом. Сообщения пользователя и ассистента идут по порядку с заголовками ролей. Поддерживаются DOCX, PPTX, XLSX, Markdown, TXT и JSON.

Для DOCX/PPTX создаётся один документ на чат; таблицы передаются в XLSX; Markdown и TXT содержат всю переданную историю. JSON сохраняет исходные объекты сообщений и их порядок, исключая только служебные роли. В офисных и текстовых форматах скрытые `<think>`/`<details>` блоки удаляются. PDF в этой функции не предлагается.

## Установка через API

Из каталога проекта выполните:

```bash
cd chat-exporter
./install-functions.sh --email ADMIN_EMAIL
```

Скрипт проверяет контейнер `open-webui`, запрашивает пароль администратора скрытым вводом и создаёт или обновляет Function `export_entire_chat`. Пароль не передавайте аргументом. Для удаления только этой Function:

```bash
./remove-functions.sh --all
```

Доступны также `--container NAME`, `--url URL` и `--email ADMIN_EMAIL`. Для ручного импорта используйте `functions.json` в Admin → Functions → Import.

## Сборка и ограничения

Из корня проекта пересоберите Action и манифест командой `python3 chat-exporter/build.py`. В готовом пакете уже есть все необходимые helper-коды. Unit-тесты запускаются из корня проекта: `python -m unittest discover -s tests -p test_chat_exporter.py -v`.

Action получает историю ветки, переданную Open WebUI в контексте вызова. Очень длинный диалог ограничен размером контекста Open WebUI. Экспорт не подключается к внешним сервисам и не меняет историю чата.
